# `cli/` — command-line entry points

Archetype: **`CLI`**

Tools a person runs from a terminal against this application: an admin command, a bootstrap script,
a developer utility distributed as a binary.

Put the code directly here to start with (`cli/admin/`). When a tool earns its own repository,
extracting this directory produces a repository with archetype `CLI`, which is re-attached as a
submodule at this same path.
